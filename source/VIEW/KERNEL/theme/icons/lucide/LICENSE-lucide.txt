All paths are unmodified from upstream lucide-static@0.460.0 except for
the addition of an XML declaration + a one-line provenance comment in
each file. The stroke uses `currentColor` so the icons inherit the
hosting widget's text color under the BALLView neutral QSS theme
(maintainer-Q3: single neutral theme only).

To refresh: download a new lucide-static release tarball, copy the
SVGs by name, re-apply the header. No build-time download.
