### Task 6 — `ThemedIconEngine` header + impl (Handover §2.2)
type=auto

New files:

- `include/BALL/VIEW/KERNEL/theme/themedIconEngine.h`
- `source/VIEW/KERNEL/theme/themedIconEngine.C`

Subclasses `QIconEngine`. `pixmap(size, mode, state)` impl:

1. Load SVG from `:/icons/<name>.svg` via `QSvgRenderer`.
2. Pick tint by `QIcon::Mode`:
   - `Normal`   → `--ink-soft`  (kInkSoft)
   - `Active`   → `--ink`       (kInk)
   - `Selected` → `--accent`    (kAccent)
   - `Disabled` → `--ink-muted` (kInkMuted)
3. Render to `QImage` at `size * devicePixelRatio()`.
4. Composite via `QPainter::CompositionMode_SourceIn`.
5. Cache keyed by `(name, size, mode, dpr)`.

**Note** per ROADMAP: state tints, NOT theme tints. Single-theme means
the 4 tint colors are constants, not theme-switched. Cache key omits
themeRevision.

Add header constants for the 4 tint colors in `tokens.h` if not
present (kInk/kInkSoft/kInkMuted/kAccent — check first; 999.40 may
already have them).

Entire engine is `#ifdef BALL_UI_V2`-gated. With the flag OFF the
files compile to empty TUs.

**Files:** `include/BALL/VIEW/KERNEL/theme/themedIconEngine.h`,
`source/VIEW/KERNEL/theme/themedIconEngine.C`,
`include/BALL/VIEW/KERNEL/theme/tokens.h` (if tint constants missing),
CMake glob picks up the new sources automatically.

**Commit:** `feat(999.42/06): ThemedIconEngine — per-DPR state-tinted SVG renderer`
