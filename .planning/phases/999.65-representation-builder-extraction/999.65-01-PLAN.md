<objective>
Create a NEW headless `RepresentationBuilder` in the MODELS layer that reproduces
`DisplayProperties::createRepresentation`'s orchestration WITHOUT any QWidget / dialog dependency.
This is step 1 of the 999.57 relocate-then-repoint pattern: build the dialog-free builder first
(this plan), then repoint the live consumers onto it one at a time (Plans 02, 03), after which
`DisplayProperties::createRepresentation` becomes dead and the displayProperties /
modelSettingsDialog / coloringSettingsDialog triple becomes deletable by 999.53.

The builder consumes the 999.57 `ModelProcessorFactory` / `ColorProcessorFactory` (already headless)
plus an explicit `RepresentationSpec` value object that carries every piece of state the legacy
`createRepresentation` read from dialog widgets (model type, coloring method, drawing mode, precision,
transparency, custom color, the two update-enable flags) so no QWidget is touched.

Purpose: VIEW-CLEAN-04 — relocate the representation-creation ENGINE off `DisplayProperties` so the
core molecule-load -> render path no longer requires the dialog. This plan is the highest-risk
extraction's foundation; it is a PURE ADDITION (nothing repointed) so it cannot regress rendering yet.

Output: `representationBuilder.{h,C}` in MODELS + its sources.cmake entry; BALLView links clean
(BALL_UI_V2=ON). NO consumer repoint in this plan.
</objective>
