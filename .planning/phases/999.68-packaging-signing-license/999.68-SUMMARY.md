## Key finding (license accuracy correction)

The phase brief's blanket "the release builds with `-DBALL_LICENSE=GPL`" is
**true for macOS only**. Ground truth from `release.yml` + `CMakeLists.txt`
(FFTW + OpenBabel are searched *only* inside `IF(BALL_LICENSE_GPL)`):

| Platform | Configure flags | Effective shipped license |
|---|---|---|
| macOS `.dmg` | `ci-macos -DBALL_LICENSE=GPL` | **GPL** (FFTW + OpenBabel linked) |
| Linux SKUs | `ci-linux -DBALL_HAS_FFTW=OFF` (no GPL flag) | **LGPL** (FFTW excluded) |
| Windows `.exe`/`.zip` | `ci-windows` (no GPL flag) | **LGPL** (FFTW/OpenBabel gated off; the `fftw3` vcpkg port is built but not compiled into BALL) |

(`ci.yml`'s Linux job *does* pass `-DBALL_LICENSE=GPL`, but that is the CI
**test** build, not the shipped Linux release artifact.) This is reflected
accurately in `LICENSE-REVIEW.md` and the BUILD docs.
