<objective>
Turn the Inspector right-rail from a plain `QDockWidget` (`InspectorDock`) into a
collapsible right-side drawer (`InspectorDrawer`) that mirrors the proven
`BottomDrawer` UX: a chevron-toggled, animated collapse to a ~24px rail on the
RIGHT edge and re-expand, with the collapsed/expanded state persisted. This is the
horizontal analog of `BottomDrawer` — animate `"maximumWidth"` instead of
`"maximumHeight"`, chevron points the chevron-left/chevron-right icons instead of
up/down.

Implements DRAWER-01.

Purpose: The Inspector should feel like a first-class collapsible panel matching
the bottom drawer, reclaiming the full 3D scene width when the user collapses it.

Output: A new `InspectorDrawer` class wrapping `InspectorView`, wired into the
mainframe in place of `InspectorDock`, with persisted expand/collapse state. The
existing `inspectorDock` objectName is preserved so WorkspaceManager presets keep
addressing it.

Design decision (locked): create a NEW `InspectorDrawer` class that MIRRORS
`BottomDrawer` rather than extracting a shared `CollapsibleDrawer` base. Rationale:
the lowest-risk path that cannot regress the already-shipped `BottomDrawer`. Add a
short comment in `inspectorDrawer.h` noting future de-duplication into a shared
`CollapsibleDrawer` base is possible but deferred.
</objective>
