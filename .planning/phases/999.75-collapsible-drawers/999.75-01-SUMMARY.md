# Phase 999.75 Plan 01: Inspector Right-Drawer (DRAWER-01) Summary

Turned the Inspector right-rail from a plain `QDockWidget` (`InspectorDock`) into a collapsible, animated right-side drawer (`InspectorDrawer`) — the horizontal analog of the shipped `BottomDrawer` — animating `maximumWidth` between a ~24px chevron rail and the 280px Inspector, with collapse/expand state persisted across restarts.

## What Was Built

- **`InspectorDrawer`** (`inspectorDrawer.h` / `.C`): a `QDockWidget` subclass that mirrors `BottomDrawer` on the horizontal axis. `QPropertyAnimation` on the `"maximumWidth"` property (200ms OutCubic), a custom title-bar rail (`kCollapsedWidth = 24`) with a chevron `QToolButton` (chevron-left to expand / chevron-right to collapse) plus a compact vertical "Inspector" identity label, `kExpandedWidth = 280` (matches the old UFG-04 `setMinimumWidth(280)`). `setExpanded(bool)` / `toggle()` slots, `expandedChanged(bool)` signal, and a min/max-width swap in the animation `finished` lambda. `animateTo()` raises the cap from the current `width()` and nudges the parent via `resizeDocks({this}, {target}, Qt::Horizontal)`. Wraps `InspectorView`, calls `view_->loadState()`, exposes `view()`.
- **macOS chrome**: the custom rail is installed via `setTitleBarWidget()` on all platforms, replacing `InspectorDock`'s macOS-only `setTitleBarWidget(new QWidget)` — same approach BottomDrawer used to solve the macOS no-chrome problem.
- **Persistence**: `InspectorView` gained `drawer_expanded_` (default `true`), `isDrawerExpanded()` / `setDrawerExpanded()`, a `[Inspector] expanded=` read in `loadState()` and write in `flushStateWrite_()`, routed through the existing 250ms debounced writer.
- **Mainframe wiring**: forward-decl + member type swapped to `InspectorDrawer` (member name `inspector_dock_` retained); construction site now builds `VIEW::InspectorDrawer`. All `->view()` / `setVisible()` / `toggleViewAction()` call sites compile unchanged.
- **Build retirement**: `inspector/inspectorDock.C` removed from `source/VIEW/WIDGETS/sources.cmake` (files kept on disk).

- **Found during:** Task 3 (link step)

- **Fix:** `LIST(REMOVE_ITEM INSPECTOR_HEADERS_LIST .../inspector/inspectorDock.h)` so the retired header is no longer moc'd; reconfigured and rebuilt clean.
- **Files modified:** `include/BALL/VIEW/WIDGETS/sources.cmake`
