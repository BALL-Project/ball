## Decisions Made

- **Offset semantics:** percent slider 0..100 → float 0..1; the plane point is shifted along its
  normal by `offset_ * 20.0` from the camera look-at position (reuses the legacy SetClippingPlane /
  scene.C `setupViewVolume` point/normal idiom). 20.0 chosen as a visible default shift distance.
- **Single-plane model:** the Inspector owns the first plane in `getClippingPlanes()`; created on
  first enable (mirroring `scene.C:3448`), disabled via `setActive(false)` rather than removed.
- **No ControllerApplyGuard for clipping:** documented in-source — the clipping/redraw path emits no
  synchronous `*Changed` back into the controller (unlike Model/Material), so the re-entrancy shield
  is unnecessary; the ModelController busy-guard (`MainControl::isBusy()` → defer) is retained.
- **Scene-bound controller:** ClippingController takes `Scene::getInstance(0)`; it has no
  `setRepresentation`, so it is resynced via `revert()` in `setActiveRepresentation` and `onTabChanged_`.
