<objective>
Improve the continuous simulation loop with (1) a status-bar progress bar during
Energy Minimization and MD (#487, FEATLOOP-01) and (2) an auto-stop when a user
quality criterion is met (#486, FEATLOOP-02). Both requirements live in the SAME
loop code — the `run()` methods of `EnergyMinimizerThread` and `MDSimulationThread`
in `source/VIEW/KERNEL/threads.C`, driven from `MolecularStructure`. They are
combined into one plan because they touch identical files (GSD forbids same-wave
file overlap across plans), and they share the per-iteration loop body.

Purpose: usability — the user currently gets no progress feedback and must guess
when to manually stop a converging run.
Output: a progress bar wired to the simulation threads, and an auto-stop check in
both run loops. This plan is autonomous (code + green build); the visual/functional
GUI confirmation happens in the Wave-2 UAT plan (999.74-03).
</objective>

  <action>
    Per FEATLOOP-01 / #487, add a `QProgressBar* progress_bar_` member to MainControl
    next to `message_label_`/`simulation_icon_`. Construct it where those status-bar
    widgets are created and `addPermanentWidget(...)` it to the status bar; start it
    hidden (`setVisible(false)`), range 0..100, text-visible. Add public methods
    `void setSimulationProgress(float fraction)` (0.0–1.0 → maps to 0..100, shows the
    bar) and `void clearSimulationProgress()` (hides + resets the bar).

    Because the simulation runs on a worker thread and Qt is not thread-safe (see the
    BALLThread doc-comment rules), the worker must NOT touch the QProgressBar
    directly. Add a `SimulationProgressMessage` to message.h/message.C mirroring the
    existing `FinishedSimulationMessage` (carry a `float fraction_` with get/set), and
    in `MainControl::onNotify` add an `else if (RTTI::isKindOf<SimulationProgressMessage>(message))`
    branch that calls `setSimulationProgress(msg->getFraction())`. Keep
    QT_NO_KEYWORDS discipline: any signals/slots use Q_SIGNALS/Q_SLOTS/Q_EMIT; here
    the message route avoids slots entirely.

    2-space indent, Allman braces, trailing-underscore members, `namespace BALL`.
