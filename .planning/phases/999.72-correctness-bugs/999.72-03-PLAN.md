<!-- From include/BALL/NMR/spectrum.iC. -->

The 1D implementation (lines ~398-470) is the working reference. It populates
three member vectors: normal_moments, central_moments, standardized_moments,
and resizes each to moment_number. It computes:
  - normal_moments[0] = average * spacing  (the m0 term)
  - normal_moments[k]  = sum over grid of pow(index, k) * data[index] / average
  - central_moments[k] = sum over grid of pow(index - normal_moments[1], k) * data[index] / average
  - standardized_moments[k] = central_moments[k] / pow(standard_deviation, k)

The 2D version (lines ~473-519) is `void computeAllMoments(int /* moment_number */)`
with the ENTIRE body commented out (a `/* ... */` block that even contains stale
`return` statements from when it was a scalar-returning function). It must be
re-implemented to mirror the 1D logic over the 2D grid (index.x / index.y,
Vector2 spacing, data_.getCoordinates(index)). The members it must populate are
the same `normal_moments` / `central_moments` / `standardized_moments` declared
on the Spectrum template.

The companion 2D method computeHuInvariants() (lines ~591-676) already shows the
correct 2D grid-traversal + moment-accumulation idiom to follow (geometric/
central moments over m_i_j).
