# Phase 999.72 Plan 03: Spectrum2D computeAllMoments Summary

Re-implemented `Spectrum<RegularData2D, Peak2D>::computeAllMoments`, a no-op since commit b499647, so it actually populates the moment vectors — mirroring the working 1D specialization (#601).

## What was built

- **Implementation** (`include/BALL/NMR/spectrum.iC`, ~line 473): replaced the fully commented-out body (which even carried stale scalar `return` statements from when the function returned a single moment) with a real `void` implementation that:
  - guards `moment_number` (`< 0` logs, `< 1` returns),
  - clears + resizes `normal_moments`, `central_moments`, `standardized_moments` to `moment_number`,
  - iterates the 2D grid in (x, y) order using the **flat linear index** `index.x + size.x*index.y` as the 1D-analog moment variable and `data_[index]` for the value,
  - computes `normal_moments[0] = average * spacing.x * spacing.y` (cell area for the m0 term), the normal moments (`pow(li,k)*data/average`), the central moments (`pow(li - normal_moments[1], k)*data/average`), and the standardized moments (`central / pow(sd, k)`).
  - Re-enabled the `int moment_number` parameter name; left the 1D specialization untouched.
- **Regression CHECK** (`test/Spectrum_test.C`, `[BUG-601]`, added to the Spectrum1D START_TEST block — the file had no Spectrum2D block): builds a deterministic 2×2 `RegularData2D` (flat values 1,2,3,4, unit spacing), constructs a `Spectrum2D` from it, calls `computeAllMoments(4)`, and asserts the moment vectors against values cross-checked by replicating the algorithm (average = 10; normal `[10,2,5,13.4]`, central `[10,0,1,-0.6]`, standardized `[10,_,1,-0.6]`). The first assertion `normal_moments.size() == 0` before the call plus `== 4` after it makes the no-op state fail unambiguously.

## Root-cause confirmation (red → green)

- **RED:** against the no-op, `computeAllMoments` leaves the vectors empty, so `TEST_EQUAL(normal_moments.size(), 4)` (and every `TEST_REAL_EQUAL`) fails.
- **GREEN:** after the implementation, all assertions pass (`checking Spectrum2D::computeAllMoments() [BUG-601]... passed`); the existing Spectrum1D ctor/dtor CHECKs still pass.
