## Deviations from Plan

None functional. Two plan-anticipated judgement calls, both documented inline as behavior-preserving:
1. **applySettingsTo retained, not removed** (displayProperties.C model ~471 / coloring ~502). The plan said "REMOVE it if redundant" — it is redundant only on the recreated-processor branch, but is REQUIRED on the not-recreated branch (precision-only / coloringUpdateEnabled-toggle) and to apply the two checkbox knobs (cartoon DNA-ladder, ribbons-enabled) that have no public getter for ModelProcessorParams. Re-applying the factory-baked params is idempotent → render output byte-identical. Removing it would have changed behavior. (Behavior-preservation, the plan's stated test.)
2. **buildColoringOverrides_ promoted to public** (a small header API change, not architectural) so displayProperties can build the dialog's exact overrides and call the factory — satisfying the must-have that displayProperties.C:487 call ColorProcessorFactory::create directly. The model side needed no equivalent (all model getters were already public).
