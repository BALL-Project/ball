<objective>
Relocate the Material and Light configuration that `scene.C` currently reaches through the legacy `MaterialSettings` / `LightSettings` dialogs into the existing Inspector `MaterialController` / `LightController`, so the render path applies material + light state through the controllers instead of the dialog `apply()` bodies.

This is the FIRST of three cut-over plans for Phase 999.58. It removes scene.C's LIVE material + light dependency on the dialogs (the `applyPreferences()` calls + the scattered `light_settings_->updateFromStage()` refresh calls). It does NOT yet remove the dialog constructions at scene.C:142/143 — that is Plan 03 (after the stage + stereo + preferences-stack relocations land). The dialog files themselves are deleted in Phase 999.53; do not delete them here.

Purpose: VIEW-CLEAN-03 requires scene.C to no longer depend on MaterialSettings/LightSettings for driving the rendered scene. The Inspector controllers already mirror a subset of the fields and write through the same Stage/Scene backend (the 999.44 cut-over recipe); this plan completes the field coverage and switches the render-refresh path over.
Output: MaterialController/LightController owning the full material/light field set; scene.C applyPreferences material+light branches and the light-refresh call sites routed through the controllers.
</objective>
