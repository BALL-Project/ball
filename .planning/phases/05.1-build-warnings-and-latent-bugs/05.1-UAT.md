**Note on shape.** This phase is a janitorial sweep: 14 plans of surgical
source-level / build-config / CI-workflow fixes with **no user-observable
behavior changes**. There is no UI to click through, no workflow to walk.
The verification oracle (per CONTEXT.md D-07) is the next clean tri-OS CI
run emitting zero of the targeted warning categories on the matched files,
plus the macOS notarization and Windows installer prerequisites being met.

The tests below are therefore **smoke checks and CI-grep assertions**
rather than conversational user-flow steps. Reply `yes` / `y` / `next` to
confirm; anything else is recorded as an issue.
