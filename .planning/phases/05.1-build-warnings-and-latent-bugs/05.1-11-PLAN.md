<objective>
Fix BACKLOG.md Task **D2** — Node.js 20 deprecation in GitHub Actions.

Every CI job currently emits:

    Node.js 20 actions are deprecated. The following actions are running on Node.js 20
    and may not work as expected: actions/checkout@v4, actions/cache@v4. Actions will be
    forced to run with Node.js 24 by default starting June 2nd, 2026. Node.js 20 will be
    removed from the runner on September 16th, 2026.

Cosmetic today, but the workflow will silently start running on Node.js 24 after the
June 2026 cutover, and then break entirely when Node 20 is removed in September 2026.
Must be resolved before September 2026.

Two fix options:
- (A) **bump action pins** — `actions/checkout@v4` → `actions/checkout@v5` and
  `actions/cache@v4` → `actions/cache@v5`, if v5 of each exists and is GA. Cleanest.
- (B) **env-flag opt-in** — set `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24=true` at workflow
  level on current pins. Validates Node 24 against current actions; preserves a clean
  fallback. Transitional.

Recommend A if v5 pins exist; else B as transitional bridge. Trivial diff (~3 lines per
workflow file). Not Codex cross-checked.

Purpose: BACKLOG.md task D2.
Output: ~3-line edits in `.github/workflows/ci.yml` and `.github/workflows/release.yml`.
</objective>
