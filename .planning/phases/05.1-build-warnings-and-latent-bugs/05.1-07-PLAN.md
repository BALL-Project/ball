<objective>
Fix BACKLOG.md Tasks **B1** + **B2** — Windows DLL hygiene for explicit template
instantiation across `vector3.h`/`vector3.C` and `atom.h`/`atom.C`.

**B1 (Codex-verified):** `vector3.h:1145,1148` declares `extern template class BALL_EXPORT std::vector<Vector3>;`
and `extern template class BALL_EXPORT TVector3<float>;`. C4910 — `extern template`
means "don't instantiate here, link from elsewhere", `__declspec(dllexport)` (which is
what `BALL_EXPORT` expands to on MSVC) means "generate code". The two are contradictory.
The matching definitions in `vector3.C:10,13` exist but lack `BALL_EXPORT`, so the
instantiation is generated unexported — clients can't link to it from the DLL.

The fix is to **move `BALL_EXPORT` from declaration site (`.h`) to definition site
(`.C`)**:

| File | Before | After |
|---|---|---|
| `vector3.h:1145` | `extern template class BALL_EXPORT std::vector<Vector3>;` | `extern template class std::vector<Vector3>;` |
| `vector3.h:1148` | `extern template class BALL_EXPORT TVector3<float>;` | `extern template class TVector3<float>;` |
| `vector3.C:10` | `template class TVector3<float>;` | `template class BALL_EXPORT TVector3<float>;` |
| `vector3.C:13` | `template class std::vector<Vector3>;` | `template class BALL_EXPORT std::vector<Vector3>;` |

**B2 (Codex-verified):** Mirror the same pattern in `atom.h:1010` —
`template class BALL_EXPORT std::vector<Atom*>;` sits directly in the header *without*
`extern`, meaning every TU that includes the header emits a definition. MSVC's COMDAT
folding makes this work but it's poor form, slows compile, and is fragile. The fix:
`atom.h` gets the `extern template class std::vector<Atom*>;` declaration,
`source/KERNEL/atom.C` gets a single `template class BALL_EXPORT std::vector<Atom*>;`
definition.

**Sequenced into one plan** (CONTEXT.md D-02) because B2 mirrors the exact B1 pattern;
landing them together avoids leaving the codebase half-converted.

Severity: Windows DLL hygiene + compile-time cost reduction.

Purpose: BACKLOG.md tasks B1 + B2 (both Codex-verified).
Output: 4 token-position edits in vector3.{h,C} + 1 declaration replacement in atom.h
+ 1 definition added in atom.C.
</objective>
