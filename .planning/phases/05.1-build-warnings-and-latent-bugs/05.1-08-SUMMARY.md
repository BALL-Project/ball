# Phase 05.1 Plan 08: B3 C4251 project-wide pragma in global.h — Summary

## One-liner

Broadened BALL's existing narrow C4251 silencing (`exception.h:16-19` push/pop
window for `std::string` in `GeneralException`) to a project-wide
`#pragma warning(disable: 4251)` inside `include/BALL/COMMON/global.h` under
`BALL_COMPILER_MSVC`, replacing ~3495 instances of the dominant Windows
warning category with a single MSVC-gated disable + 14-line rationale comment.

## What was done

**One source change**, one commit (`9c34b24`):

- `include/BALL/COMMON/global.h`: added `#pragma warning(disable: 4251)` plus a
  14-line rationale comment immediately after the existing `BALL_VIEW_EXPORT`
  macro definitions inside the `#ifdef BALL_COMPILER_MSVC` block at line ~25.
  The pragma is implicitly guarded by the enclosing `#ifdef BALL_COMPILER_MSVC`
  — no additional ifdef needed.

The comment block documents:
1. What C4251 means (DLL-exported class with non-exported STL member)
2. The Phase 4 baseline census (~3495 instances in CI run 25899905204)
3. The Phase 4 vcpkg-pin precondition that makes the disable cosmetic-only
   (single MSVC toolchain + single STL ABI across libBALL + every client TU)
4. The relationship to the narrow push/pop window in `exception.h:16-19`
   (kept as belt-and-suspenders, redundant once this disable is active)
5. When a future maintainer must remove the disable (build matrix change)

complete, which is operationally equivalent: warnings were not emitted in

project-wide disable should subsume the entire ~3495-instance noise floor.
