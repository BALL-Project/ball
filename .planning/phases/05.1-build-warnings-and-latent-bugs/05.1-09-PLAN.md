<objective>
Fix BACKLOG.md Tasks **B4** + **B5** — Tier-B cosmetic Windows MSVC warnings.

**B4 (C4996, 5 instances):** `BALL::GeneticIndividual` is deprecated, but its
`operator=`, `~GeneticIndividual`, and ctor are still invoked from inside STL containers
that hold `GeneticIndividual` instances (vector / utility / xmemory). The container's
internal machinery triggers the warning when it instantiates the deprecated methods. Three
audit-choice fixes:

- (a) un-deprecate the methods still used internally
- (b) refactor BALL to stop holding `GeneticIndividual` in STL containers (or stop using
  the deprecated methods inside BALL itself)
- (c) add a narrow `#pragma warning(suppress: 4996)` at the STL-instantiation sites

Pick the cheapest option; cosmetic only. Not Codex cross-checked.

**B5 (C4834, 1 instance):** `source/QSAR/regressionModel.C:258` discards a
`[[nodiscard]]` return value. Read the line, decide whether the return value should be
checked or explicitly discarded with `(void)` or `[[maybe_unused]]`. Small, isolated.
Not Codex cross-checked.

**Bundled into one plan (CONTEXT.md D-02)** because both are tiny Tier-B cosmetic
items in the same plan-budget; bundling keeps the per-plan overhead reasonable.

Purpose: BACKLOG.md tasks B4 + B5.
Output: one-line edit at regressionModel.C:258 plus a small per-site remediation for B4
(exact file list determined by audit, recorded in SUMMARY).
