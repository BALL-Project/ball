**Categorization rubric (each warning entry → exactly one of):**
- **(a) Mechanical-fix** — formula-driven repair. Examples:
  - `-Wdeprecated-copy` on copy constructors that should be `= default` (drop the empty body)
  - Trivial `-Wcatch-value` lift to `catch(const T&)` from `catch(T)`
  - `-Wunqualified-std-cast-call` qualifications (add `std::`)
  Target: **999.22a → v1.7** (or smaller v1.6.3 cycle if one materializes; v1.7 is the default).
- **(b) Defer-to-v2.0 (blocked-by-999.6)** — fixed-function OpenGL deprecation noise. Phase 999.6 PIPE-01 renderer rewrite dissolves these by deleting the call sites. Cleaning in v1.6.x is wasted work — they evaporate when the renderer is rewritten. Target: **999.22b → v2.0**.
- **(c) Defer-to-v1.7 (per-site review)** — needs real per-call-site code review. Could be intent question (deprecated-copy on classes with non-trivial copy semantics — was the empty body intentional?), correctness concern (catch-by-value of large derived exception with slicing risk), or design question (`[[nodiscard]]` on functions whose return is genuinely optional). Target: **999.22c → v1.7** alongside the UI refresh that's already on v1.7.

**Tool inventory for the census step (use only what already exists; no new infra):**

- Parse: `grep -E "warning:.*(\\[-W|\\[C[0-9]+\\])" {log} | awk` to extract file:line:warning-name, then group/sort.

**The atom.h intentional warning (must-flag-not-fix):**
