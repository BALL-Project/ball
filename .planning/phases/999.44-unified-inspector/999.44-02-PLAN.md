# Phase 999.44 Plan 02 — Mainframe wiring for Unified Inspector

## Objective

Make the Inspector dock reachable from the BALLView UI. Plan 999.44-01 shipped the architectural shell behind `BALL_UI_V2` but explicitly deferred mainframe registration (Task 2 deferral, parallel-agent risk with 999.45). With 999.45 now landed, wire:

1. `InspectorDock` added on the right rail under `BALL_UI_V2`.
2. `View ▸ Hide Inspector` checkable action with `Ctrl+\` shortcut.
3. `Tools ▸ Legacy Settings ▸ <12 entries>` submenu populated from `LegacySettingsHelper`.
4. First-run migration `QMessageBox::information` gated by `[Inspector] firstRunMigrationNoticeShown`.

## Tasks

### Task 1 — Mainframe wires InspectorDock + View ▸ Hide Inspector + Tools ▸ Legacy Settings

**Type:** auto

**Files:**
- MODIFIED: `source/APPLICATIONS/BALLVIEW/mainframe.C`
- MODIFIED: `source/APPLICATIONS/BALLVIEW/mainframe.h` (add inspector_dock_ + slot)

**Behavior:**
- Under `BALL_UI_V2`: construct `InspectorDock`, `addDockWidget(Qt::RightDockWidgetArea, ...)`.
- `View ▸ Hide Inspector` action, checkable, `Ctrl+\` shortcut, wired to `inspector_dock_->setVisible`.
- `Tools ▸ Legacy Settings ▸` submenu populated by iterating `LegacySettingsHelper::legacyStackNames()`. Each entry resolves to a `PreferencesEntry*` matching that stack name and calls `Preferences::showEntry(...)` to surface the right page.
- First-run `QMessageBox::information` on first `show()` with `BALL_UI_V2`, gated by `[Inspector] firstRunMigrationNoticeShown` in `~/.BALLView`.

**Done when:**
- `BALL_UI_V2=ON` build is green on macOS-arm64.
- `BALL_UI_V2=OFF` build is unchanged (no Inspector wiring compiled).
- Application launch with `BALL_UI_V2=ON` exposes the Inspector dock on the right rail.
