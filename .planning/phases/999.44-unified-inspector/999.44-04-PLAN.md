# Phase 999.44 Plan 04 — Representation tab (sub-PRs 4.3 + 4.4)

## Objective

Land the Representation tab: Controllers + sections so the user sees + edits Model / Coloring / Material / Label / Clipping per-Representation settings via the Inspector instead of opening 4 separate legacy dialogs.

## Scope decision (operating-contract scope-trim)

Read-only mirror Controllers for all 5 dialog domains; sections for **Model / Coloring / Material** (the three highest-traffic dialogs per Handover §04). **Label / Clipping** sections deferred to a 999.44-04b RC patch — their Controllers ship now so the cut-over is mechanical when the sections land.

Rationale: 5 sections × ~250 LOC each = 1250 LOC of section UI alone; given token budget, 3 sections + 5 Controllers is the load-bearing minimum to demonstrate the pattern across multiple Controllers + show real user-visible Inspector content.
