## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Header `#ifdef BALL_UI_V2` outer-wrap blocked AUTOMOC discovery of Q_OBJECT**
- **Found during:** Task 1 build (vtable-missing link errors on InspectorTabs / InspectorSection)
- **Issue:** AUTOMOC's preprocessor scan runs with project-wide MOC_DEFINITIONS but apparently does not apply `BALL_UI_V2` in the way I expected when the entire header is wrapped. Both `inspector*.h` files compiled into the source but moc didn't generate `moc_*.cpp` for them, so the Q_OBJECT vtables were absent at link time.
- **Fix:** removed the outer `#ifdef BALL_UI_V2` wrap from the 5 Inspector headers + the 2 sections headers + the StageController header + the InspectorEmptyState header. The .C bodies remain `#ifdef BALL_UI_V2`-wrapped so the OFF cell still produces empty TUs and the linked binary carries no Inspector symbols at all. This matches the 999.43 IconBrowser precedent.
- **Files modified:** all 9 Inspector / Controller headers.
- **Commit:** included in `f8a5063897` (Task 1 commit landed the corrected pattern).

**2. [Rule 3 - Blocking] `ADD_VIEW_HEADERS` macro flattens basenames, dropping subdir paths**
- **Found during:** Task 1 second build attempt (after the header gating fix)
- **Issue:** `ADD_VIEW_HEADERS(GROUP HEADERS_LIST)` runs `GET_FILENAME_COMPONENT(i ${i} NAME)` and prefixes `include/BALL/${GROUP}/${i}`. My `inspector/inspectorSection.h` became `include/BALL/VIEW/WIDGETS/inspectorSection.h` (no `inspector/` subdir), which CMake then complained didn't exist, killing the configure step.
- **Fix:** append the inspector subtree to `VIEW_headers` directly (bypassing the macro) + add SOURCE_GROUP so IDE tree stays organised. Applied the same pattern for the controllers subtree.
- **Files modified:** `include/BALL/VIEW/WIDGETS/sources.cmake`, `include/BALL/VIEW/KERNEL/sources.cmake`.
- **Commit:** `f8a5063897` (WIDGETS) + `6018ee5787` (KERNEL).

**3. [Rule 1 - Bug] `Icons::get(std::string)` vs `Icons::get(const char*)` mismatch**
- **Found during:** Task 3 build
- **Issue:** `IconRegistry::get` takes `const char*` not `std::string`; my `iconKey.toStdString()` triggered ambiguous-conversion errors against multiple `Icons::get` overloads.
- **Fix:** `iconKey.toUtf8().constData()` returns `const char*` directly.
- **Files modified:** `source/VIEW/WIDGETS/inspector/inspectorEmptyState.C`.
- **Commit:** `13914db2fc`.

**4. [Rule 1 - Bug] `ColorRGBA::getRed/Green/Blue` returns `ColorUnit` not `float`; operator* ambiguous**
- **Found during:** Task 4 build
- **Issue:** `ColorUnit` has many conversion operators (char/int/float/etc.); multiplying by a `255.0f` literal triggered ambiguity errors against the built-in integer/float operator*s.
- **Fix:** explicit `static_cast<float>(...)` before the multiply.
- **Files modified:** `source/VIEW/KERNEL/controllers/stageController.C`.
- **Commit:** `6018ee5787`.

**5. [Rule 1 - Bug] CI linux-x64 OFF cell — undefined Q_OBJECT vtables on Inspector classes (post-push fix)**
- **Found during:** CI run `25996552601` — linux-x64 ui_v2=OFF cell completed/failure
- **Issue:** I left the Inspector headers UNCONDITIONAL (a misdiagnosis of an earlier ON-cell stale-AutogenInfo failure) thinking AUTOMOC needed unconditional Q_OBJECT visibility. Consequence: AUTOMOC's OFF-cell scan still generated `moc_*.cpp` files for the Inspector classes; those generated files reference each class's `staticMetaObject`, vtable, slot bodies — none of which exist because the `.C` TUs are `#ifdef BALL_UI_V2`-wrapped. OFF cell link fails on the dangling symbols.
- **Fix:** restore the outer `#ifdef BALL_UI_V2` on all 8 Inspector + Controller + StageSection headers. AUTOMOC's OFF-cell preprocessor finds no Q_OBJECT and generates no moc file; OFF link is clean. ON cell still works because cleaning `VIEW_autogen/CMakeFiles/VIEW_autogen.dir` before the configure pass forces a fresh AUTOMOC scan that DOES find Q_OBJECT (BALL_UI_V2 is in MOC_DEFINITIONS for the ON cache per AutogenInfo.json). Local verify: both `build/ci-macos` (ON) and `build/999.44-off` (OFF) link green; 8 moc_*.cpp generated for ON, 0 for OFF as expected.
- **Files modified:** 8 headers + 8 .C files (`include/BALL/VIEW/WIDGETS/inspector/{,sections/}*.h`, `include/BALL/VIEW/KERNEL/controllers/stageController.h`, matching `.C`).
- **Commit:** `1d76af2e70`.
