# `999.59` — Controller cut-over · command-shaped `apply()`

**Codename:** *the contract*
**Wave:** A · gating
**Effort:** ~1 week
**Risk:** medium (touches every Controller TU)

## Goal

Land the command-shaped `Controller::apply()` contract on every
mutating Controller in the VIEW layer. Replace the 5 read-only-mirror
Controllers with mutating ones. Narrow owner-side setters so external
mutation does not compile.

This is the **gating phase** for v1.7.4 — `999.60`/`999.63`/`999.64`
all depend on the contract being in place.

## Why now

`v1.7.x-ARCHITECTURE-REVIEW.md` identified the dual-path mutation
defect behind ~30 UFG bug reports. The current Controllers are *setter
bundles* (`setX(); apply(); notify()`) — that shape is what allows
re-entry, mid-state observation, and notification ordering issues to
keep biting.

The contract makes mutation a **transaction**, not a sequence of
public calls.

## Scope

**In:**
- Base `Controller` class + `ApplyGuard` + `ApplyPayload` types.
- Migration of the 3 already-mutating Controllers (Model, Coloring, Material) to the new shape — validates the contract.
- Cut-over of the 5 remaining (Camera, Light, Stereo + Clipping/Label follow-ups from 999.51).
- Owner-side `friend`-narrowing on `Stage` and `Representation`.
- Reversible-payload capture (storage only; no UI consumer in v1.7.4).
- `ControllerJob` base for async operations (used by future minimization/FDPB Controllers).

**Out:**
- Undo stack — `999.59-05` captures the payload; v2.0 consumes.
- `ConnectionObject` replacement — v2.0.
- Python binding regeneration — v2.1.
- New owner-side state.
- New Inspector controls — `999.63` and `999.64` do that, *consuming* this contract.

## Cross-platform notes

The contract is platform-agnostic. Two platform-specific touches:

- **macOS:** `ControllerJob`'s worker thread must NOT touch the GL context. `Renderer::query…()` methods on the GUI thread are the only legal accessors. UFG-26 was a `QPainter` on `QOpenGLWidget` off the paint cycle — the same shape.
- **Windows:** MSVC's strict `friend` lookup needs `friend class StageController;` *inside* the `Stage` definition (not a forward decl in a header outside). One pass in `999.59-04` covers it.

## Risks & rollback

| Risk | Severity | Mitigation |
|------|----------|------------|
| Narrowing breaks the Python binding | med | `999.59-04` documents the binding-time surface; SIP refresh runs in CI. |
| `friend`-grant explosion (file-IO writers need Representation mutation) | med | Introduce `RepresentationBuilder` as the single legal mutation surface for non-Controller TUs. ~80 LOC, lives in `KERNEL`. |
| Contract-test infra not ready in `999.60` | low | Land `999.59-02` (3 known-good Controllers) FIRST; verify by hand; then `999.60` ships against it. |
| `ApplyGuard` re-entry semantics surprise a future implementer | low | The base header carries 30 lines of doc-comments + 3 examples. Audit in code review. |

**Rollback:** the contract lands behind no flag — once committed, it's
the only shape. Revert path is per-Controller `git revert` if a
specific Controller's cut-over regresses; the base types stay.
