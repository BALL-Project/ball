**Per-conflict diagnostic flags:**
Bison's `-Wcounterexamples` (added in 3.7) prints, for each shift-reduce conflict, an actual token stream that triggers the ambiguity — invaluable for understanding what real CIF input shape the conflict represents. Combine with `-v` to dump the full LALR state machine into a `.output` file:
```bash
bison -Wcounterexamples -v -o /tmp/cif-parser.C source/FORMAT/CIFParserParser.y
# Produces /tmp/cif-parser.output with state machine + conflict explanations
```

**Default-precedence vs. CIF-spec correctness check:**
Bison defaults to "prefer shift over reduce" for shift-reduce conflicts. For each conflict, the audit must confirm: does shifting (Bison's default) match what the [CIF 1.1 spec](https://www.iucr.org/resources/cif/spec/version1.1) (or the dictionary the parser is implementing) actually wants? If yes → BENIGN-CONFIRMED. If no → the grammar has a real bug and needs a FIX (either rule restructuring or an explicit `%left`/`%right`/`%nonassoc` precedence declaration).

**The two resolution paths:**
- **Grammar fix:** Restructure the ambiguous rule pair OR add explicit precedence (`%left TK_xxx` etc.). Preferred when the fix is small and clarifies intent. Re-running Bison shows fewer conflicts.
- **`%expect N` acceptance:** Add `%expect N` near the top of `CIFParserParser.y` declarations, where N is the count of conflicts that were triaged as BENIGN-CONFIRMED. Bison then runs silently for that exact count and errors out if the count changes (which is the GOOD behavior — future drift gets caught). Use when all conflicts are confirmed-benign and grammar restructuring would be invasive.

**Combined approach is fine:** fix the N conflicts that are real bugs; leave the M benign ones; declare `%expect M` for the residue.

**What AUDIT.md must capture per conflict:**
| # | Rule pair (state ID) | Token | Default action | CIF-spec correct? | Disposition | Commit |
| 1 | rule_X / rule_Y (state 42) | TK_VALUE | shift rule_X | YES (literal-value shadowing) | BENIGN-CONFIRMED | — |
| 2 | rule_A / rule_B (state 67) | TK_LOOP | shift rule_A | NO (should reduce rule_B for save_frame nesting) | FIX | abc123 |
| ... | ... | ... | ... | ... | ... | ... |

(See [AUDIT.md](AUDIT.md) for the stub the execution agent populates.)

Expected post-fix: zero conflict-warning lines (if all fixed), OR Bison runs silently because `%expect N` matches.
