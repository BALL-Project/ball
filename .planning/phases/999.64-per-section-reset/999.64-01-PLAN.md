# `999.64` — Per-section "Reset section" affordance

**v1.7.x-36 (new)** · Wave B · ~1–2 days

> **Ingest note (2026-05-22).** The handover PLAN.md minted this as `v1.7.x-31 (new)`, but `v1.7.x-31` is already used in this repo for the #501 renderer-plugin startup-warning item (Phase 999.54). Re-minted to the next free patch-queue ID **v1.7.x-36** during ingest. The handover phase id `999.63` was renumbered to **999.64** (+1) to clear the collision with the in-flight `999.58` set.

## Goal

Add one "Reset section" affordance to every Inspector section's
header. Clicking reverts that section's Controller to method-defined
defaults, through the §2 contract. Tiny, codifies a missing
affordance across all 14 sections.

## Why now

Currently sections have ad-hoc "reset to defaults" buttons on
individual rows (the LabeledSlider type-spec-specific resets) but
there is no consistent **section-level** reset. User feedback during
v1.7.0 UAT flagged this in the v1.7.x-18 patch entry. The contract
from `999.59` gives us a free implementation:
`Controller::reset()` is just `setX(defaults_)` + `apply()`.

## Scope

**In:**

1. `Controller::reset()` virtual added to the base class (`999.59-01`
   already defines the base). Every Controller overrides:
   - Captures current state.
   - Calls its setters with default values.
   - Calls `apply()`.
   The single `apply()` carries the `ApplyPayload` with before=current,
   after=defaults — undoable in v2.0.
2. `InspectorSection` header gains a small `Reset` glyph (the
   existing `reset` icon from the Lucide bundle) that appears on
   header-hover. Tooltip: "Reset section to defaults".
3. Click handler calls the bound Controller's `reset()`.

**Out:**
- "Reset all sections" — separate v1.7.5 affordance (different scope).
- Per-row reset cleanup — orthogonal, v1.7.5.
- Reset-confirmation dialog — explicit decision: no, because v2.0 undo
  makes accidental reset trivially recoverable, and the contract
  already captures the payload.

## Files touched

**Edited:**
- `inspectorSection.{h,C}` — add the glyph button, hover state, click handler.
- `controller.{h,C}` (base) — declare `virtual void reset() = 0;` (or non-virtual with `applyDefaults_()` hook — decide in plan).
- All 9 Controllers — implement `reset()` (~10 LOC each).

## Acceptance criteria

- [ ] Every of the 14 sections shows a Reset glyph on header hover.
- [ ] Clicking reset reverts the section's state to the Controller's defaults.
- [ ] One `ApplyPayload` emitted per reset (verified by counting
  events in a contract test).
- [ ] No flicker / no transient "between defaults and current" state — `ApplyGuard` from `999.59` already protects this.
- [ ] Reset works on the read-only sections too (Properties / Summary / RepHeader) — they implement `reset()` as a no-op + comment.

## Risks

- **Defaults vary by Representation type.** A SES Surface's "default sphere radius" is nonsensical. Each Controller's `reset()` is allowed to delegate to a Representation-type-aware default-provider — `999.59`'s payload already carries `target`.

## Hand-off pointer

`ARCHITECTURE-CONTRACT.md §2` — the reset goes through the same
`apply()` shape. Don't bypass it.
