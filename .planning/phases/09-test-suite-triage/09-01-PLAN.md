**Triage disposition shapes:**
- **FIXED:** root cause located + patched; test now passes locally + in CI. Smallest scope; record commit hash in 09-TRIAGE.md.
- **QUARANTINED:** mark with `set_tests_properties(<name> PROPERTIES WILL_FAIL TRUE)` in the test's CMakeLists fragment + add a comment block explaining what's quarantined and why + open a follow-up backlog stub. Test continues to run but ctest treats failure as expected. Used when the failure is real-but-non-trivial and we'd rather flip the gate now than block on a deep fix.
- **KNOWN-CASUALTY:** explicit decision that this failure is acceptable in v1.6.x and won't get fixed pre-v2.0. Document in 09-TRIAGE.md + add `WILL_FAIL TRUE` + cross-reference the v2.0 phase that will revisit. Strictly the highest bar — needs justification stronger than quarantine.
