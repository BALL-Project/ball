## 2. Architecture contract — the structural gates

These are the contract from `ARCHITECTURE-CONTRACT.md` translated to
testable pass/fail.

### 2a. Single mutation funnel

- [ ] `git grep -nE '(stage_|stage->|getStage\(\)->|representation_->|rep_->|rep->|new_rep->)set[A-Z]' source/VIEW/ ':!source/VIEW/KERNEL/controllers/' ':!*test*'`
      returns ONLY the builder/render allowlist from
      `ARCHITECTURE-CONTRACT.md §3a` (standardDatasets / gridVisualizationDialog /
      labelDialog / fieldLineCreator / geometricControl / molecularControl
      label-build / scene.C raytracer-material / glRenderer drawing-precision /
      displayProperties residual builder — all routed through
      `RepresentationBuilder` or a named per-setter `friend`). EVERY
      interactive site (modifyRepresentationDialog / interactionModeManager /
      stereoSettingsDialog / scene.C restoreViewPoint) is GONE.
- [ ] Every Controller's `apply()` returns `bool` and matches the `ARCHITECTURE-CONTRACT.md §2` shape (code review enforces).
- [ ] Each Controller declares its §2a invalidation level: Model rebuilds display lists, Stage declares its scene-structural side effects, all others soft-refresh. No blanket `update(false)`/`update(true)` rule.
- [ ] `Stage` mutation is funneled through the single `StageMutation` facade (one friend, not five). `Representation` mutation through the single `RepresentationBuilder` friend. Direct external call fails to compile (verified by `999.60` owner-narrowing compile tests, both negative-fails and positive-compiles).

### 2b. Contract tests

- [ ] `ctest -L contract` runs ≥25 tests on Linux CI; all enabled ones green.
- [ ] Per-Controller parity tests cover **all 9** Controllers (Model / Coloring / Material / Clipping / Label / Stage / Camera / Light / Stereo). Each fixture flipped from `DISABLED_` to green as its controller was cut over.
- [ ] Toolbar/menu surface helpers invoke the **registered CommandRegistry command body** (the §8 migrated `std::function`), not `action->trigger()` indirection.
- [ ] Selection-consumer agreement test (`tree / scene / control / action`) passes.
- [ ] Re-entrancy test (`apply` during own emission → `apply()` returns `false`) passes.
- [ ] Owner-narrowing compile-fail tests assert the right diagnostic (negative fails to compile; positive-through-friend compiles).
- [ ] `coloring_preview_nonmutation_test` passes: `previewRange()` mutates nothing, emits no event, never enters `apply()`.

### 2c. Re-entrancy

- [ ] No `apply()` body calls another Controller's `apply()` synchronously (audit pass during `999.59` code review).
- [ ] `ControllerApplyGuard` (nest-aware) present in **every** `apply()` implementation — INCLUDING `ClippingController::apply()` (the prior omission is closed).
- [ ] The guard is documented GUI-thread-only (nest-aware flag, not a mutex); the only cross-thread path (`ControllerJob`) re-enters the GUI thread before taking the guard.
- [ ] Bus re-entry into a Controller mid-`apply()` is silently dropped (`apply()` returns `false`) + logged at `Log.info()` (verified by `999.60` re-entrancy test).

### 2d. Reversible payload

- [ ] Every `apply()` calls `recordIntent_(payload)`.
- [ ] No UI consumer of the payload exists in v1.7.4 (intentional — v2.0 scope).
- [ ] Payload `before` / `after` fields are populated and the `command_id` is unique per Controller × operation.

### 2e. Python binding refresh (v1.7.4 gate — Codex HIGH #4)

- [ ] `source/PYTHON/EXTENSIONS/VIEW/representation.sip` no longer exposes the narrowed setters (`setTransparency` / `setDrawingMode` / `setColoringMethod` / `setModelType` / …).
- [ ] `source/PYTHON/EXTENSIONS/VIEW/controllers.sip` exists and exposes the 9 Controllers' public surface.
- [ ] The legacy direct-setter Python attribute path emits a `DeprecationWarning` naming the controller-surface replacement (one-release shim; removed in v1.8).
- [ ] A CI **SIP-refresh build-check** regenerates the bindings and compiles them; green on the merge commit.

### 2f. Qt-lifetime

- [ ] `.planning/codebase/QT-LIFETIME.md` exists; canonical.
- [ ] All 6 UFG-flagged sites cleaned.
- [ ] `lifetime-discipline` CI job green on every commit.

### 2g. Opaque-paint

- [ ] `opaque-paint-lint` CI job present. **Warn-only (STATUS) at landing**; the BLOCKING flip is a separate later commit gated on one clean STATUS week (Codex LOW #12).
