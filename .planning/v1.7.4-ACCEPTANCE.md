## 2. Architecture contract — the structural gates

These are the contract from `ARCHITECTURE-CONTRACT.md` translated to
testable pass/fail.

### 2a. Single mutation funnel

- [ ] `git grep -nE '(stage_|stage->|representation_->|rep_->)set[A-Z]'  source/VIEW/  ':!source/VIEW/KERNEL/controllers/' ':!test/'`
      returns ONLY allowlisted file-IO sites (`MolecularFileDialog`,
      `PDBFile`, `RepresentationBuilder`, ≤8 total).
- [ ] Every Controller's `apply()` body matches the `ARCHITECTURE-CONTRACT.md §2` shape (code review enforces).
- [ ] `Stage` + `Representation` mutation methods are `friend`-scoped to their matching Controllers; direct external call fails to compile (verified by `999.60` owner-narrowing compile tests).

### 2b. Contract tests

- [ ] `ctest -L contract` runs ≥25 tests on Linux CI; all green.
- [ ] Per-Controller parity tests cover every still-mutating Controller (8 expected).
- [ ] Selection-consumer agreement test (`tree / scene / control / action`) passes.
- [ ] Re-entrancy test (`apply` during own emission → drop) passes.
- [ ] Owner-narrowing compile-fail tests assert the right diagnostic.

### 2c. Re-entrancy

- [ ] No `apply()` body calls another Controller's `apply()` synchronously (audit pass during `999.59` code review).
- [ ] `ApplyGuard` RAII present in every `apply()` implementation.
- [ ] Bus re-entry into a Controller mid-`apply()` is silently dropped + logged at `Log.info()` (verified by `999.60` re-entrancy test).

### 2d. Reversible payload

- [ ] Every `apply()` calls `recordIntent_(payload)`.
- [ ] No UI consumer of the payload exists in v1.7.4 (intentional — v2.0 scope).
- [ ] Payload `before` / `after` fields are populated and the `command_id` is unique per Controller × operation.

### 2e. Qt-lifetime

- [ ] `.planning/codebase/QT-LIFETIME.md` exists; canonical.
- [ ] All 6 UFG-flagged sites cleaned.
- [ ] `lifetime-discipline` CI job green on every commit.

### 2f. Opaque-paint

- [ ] `opaque-paint-lint` CI job green (STATUS or BLOCKING, depending on the rollout-week phase).
- [ ] `data/BALLView/theme/THEME.md` exists.
- [ ] Manual smoke: expand/collapse every Inspector section on all 3 OSes; no text ghosting in the transient frames.
