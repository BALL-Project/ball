       Current: `std::count_if(box_.begin(), box_.end(), std::not1(std::mem_fun_ref(&HashGridBox3<Item>::isEmpty)))`.
       `mem_fun_ref` is REMOVED in C++17 and `not1` is deprecated — fold BOTH into one lambda.
       Replace the predicate with a lambda that returns the negation of `isEmpty()`, e.g.:
       `std::count_if(box_.begin(), box_.end(), [](const HashGridBox3<Item>& box) { return !box.isEmpty(); })`.
       Confirm the element type of `box_` (it iterates `HashGridBox3<Item>`); match the
       lambda parameter type to whatever the iterator dereferences to (const ref).

    2. `source/CONCEPT/enumerator.C` line ~133, in `EnumeratorIndex` (the `std::transform`
       updating `base_multipliers_`):
       Current third arg: `std::bind2nd(std::multiplies<Position>(), modulus)`.
       Replace with a lambda capturing `modulus`, e.g.:
       `[modulus](Position m) { return m * modulus; }`.
       This multiplies each existing multiplier by `modulus` — preserve that exact semantics.

    3. `source/STRUCTURE/DNAMutator.C` lines ~247 and ~258 (two `std::for_each` over
       `to_optimize_`):
       Line ~247 current: `std::for_each(to_optimize_.begin(), to_optimize_.end(), std::mem_fun(&Atom::select))`.
       Line ~258 current: `std::for_each(..., std::mem_fun(&Atom::deselect))`.
       Note `mem_fun` (unlike `mem_fun_ref`) expects pointer elements — `to_optimize_`
       holds `Atom*`. Replace each with a lambda taking the pointer element and calling
       the method, e.g. `[](Atom* atom) { atom->select(); }` and
       `[](Atom* atom) { atom->deselect(); }`. Verify the element type of `to_optimize_`
       in the surrounding code and match the lambda parameter accordingly (it is a
       container of `Atom*`).
  </action>
