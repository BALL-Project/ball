<objective>
Fix BACKLOG.md Task **D1** — Qt5LinguistTools missing on Windows vcpkg.

The Windows CI Configure step emits

    CMake Warning at C:/vcpkg/scripts/buildsystems/vcpkg.cmake:908: By not providing
    FindQt5LinguistTools.cmake ... CMake did not find one.

Impact: the `lupdate` / `lrelease` translation pipeline is silently skipped on Windows.
The build proceeds without translations. macOS / Linux are unaffected (system Qt
provides linguist tools).

Two fix options:
- (a) **add `qt5-tools` (or `qttools` for Qt 6) to `vcpkg.json`** so vcpkg provisions
  the tools port on Windows. BACKLOG also documents the related D6 issue —
  `windeployqt.exe` is also missing from the vcpkg-installed surface, and `qt5-tools`
  fixes both. **Recommended.**
- (b) **make the LinguistTools dependency explicitly optional** in `CMakeLists.txt` so
  the warning isn't emitted on the platform where it's expected to be missing.

Pick whichever is less work to verify. Not Codex cross-checked.

**Cross-reference with BACKLOG D6:** the v1.6.0 tag already had `qt5-tools` added
(commit `c394543`); for `v1.6-modernization` HEAD (Qt 6 era post-Phase-5) the
equivalent is `qttools`. Whichever Qt version this branch tracks dictates which port
name to add.

Purpose: BACKLOG.md task D1.
Output: a 1-line addition to `vcpkg.json` (option a) OR a conditional block in
`CMakeLists.txt` (option b).
</objective>
