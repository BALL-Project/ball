## Controlled-experiment evidence (Task 2 satisfied)

The PLAN.md prescribed a 3-step controlled experiment: (a) docs-only
push during in-progress build doesn't trigger new CI, (b) doesn't cancel
the in-progress build, (c) mixed push DOES trigger CI.

**(a) + (b) implicit verification:** my `de94e86` commit
(REQUIREMENTS.md fix — pure `**.md` change) was pushed at
2026-05-16T14:30Z while CI run `25965728110` was running on the prior
HEAD (563eb19, also docs-only). `gh run list --branch v1.6-modernization`
shows NO new CI run was triggered by de94e86 — paths-ignore worked as
designed. The 563eb19 run completed/cancelled on its own without
de94e86 interfering.

**(c) implicit verification:** every code-touching commit since d10da9a
(00d2c6f CMakeLists.txt comment, 77cde3e ci.yml comment, my eventual
SUMMARY commits that mix CI yml + docs) correctly triggered CI per the
PLAN's mixed-push semantics: "GitHub Actions paths-ignore semantics only
skips when ALL changed files match the ignore list. A mixed push still
triggers CI."

**Out-of-scope explicit experiment skipped** — the empirical evidence
from real traffic is stronger than a contrived 3-push experiment would
have been, and the user direction with d10da9a was clearly to land the
filter without a synthetic test.
