# Phase 999.41 — Plan 01: SVG icon wedge + HiDPI fixup

## Objective

Add an SVG-preferred icon path to BALLView under the `BALL_UI_V2` build
flag, vendor a 14-icon Lucide subset for the most-visible
toolbar/dock chrome, and bump the toolbar icon size from 22 to 20
logical px. Zero behaviour change when `BALL_UI_V2=OFF` (the v1.7
default).

## Context

- Source-of-truth: `Claude Design Handover/revitalization/02-phase-icons.md`
- Research: [`RESEARCH.md`](RESEARCH.md)
- Built on: 999.40 (ThemeManager + neutral QSS, `BALL_UI_V2` flag, commit `fdeca85b64`)
- Maintainer-Q3: SINGLE NEUTRAL THEME ONLY (no light/dark — no per-mode tinting in this phase)
- Wave 4 scope: macOS-only smoke-build per commit (Linux/Windows untouched in this phase)

## Acceptance criteria

1. With `-DBALL_UI_V2=OFF` (default) the BALLView binary is
   functionally identical to the pre-phase build — same icons, same
   sizes, same code paths.
2. With `-DBALL_UI_V2=ON` BALLView's toolbar/menu icons that have
   Lucide equivalents render from `:/icons/<name>.svg` instead of the
   PNG path, at the new 20×20 logical toolbar size.
3. `IconLoader::getIcon(...)` API is unchanged. No call site touches
   the loader API.
4. The `theme.qrc` bundle from 999.40 is extended in-place — single
   QRC, single Qt6_ADD_RESOURCES line.
5. macOS clean build (`cmake --build build/ci-macos --target BALLView`)
   succeeds with both `BALL_UI_V2=ON` and `BALL_UI_V2=OFF`.
6. Per-task atomic commits; each commit builds.

### Task 4 — Add SVG-preferred path inside IconLoader::loadIcon_

**type:** auto

In `source/VIEW/KERNEL/iconLoader.C`, prepend an SVG-first branch at
the top of `loadIcon_(name)` guarded on `#ifdef BALL_UI_V2`:

```cpp
#ifdef BALL_UI_V2
  // Phase 999.41 wedge: prefer a compiled-in SVG when present.
  // Falls through to the legacy PNG-from-disk walk below otherwise.
  const QString svg_path = QStringLiteral(":/icons/") + name.c_str() + ".svg";
  if (QFile::exists(svg_path))
  {
    QIcon* result = new QIcon(svg_path);
    if (!result->isNull())
    {
      icon_map_[name] = result;
      return result;
    }
    delete result;
  }
#endif
```

Add the `#include <QtCore/QFile>` near the top with the other Qt
includes. Header (`iconLoader.h`) needs no signature change — the
shim is internal.

**Files:**
- `source/VIEW/KERNEL/iconLoader.C` (edit)

**Done:** With `-DBALL_UI_V2=ON`, `IconLoader::instance().getIcon("actions/quicksave")`
returns an icon backed by the Lucide SVG (verified by `QIcon::name()`
being empty + `availableSizes()` returning the SVG's renderable sizes,
not the fixed PNG ladder). With `-DBALL_UI_V2=OFF`, behaviour is
unchanged.

**Commit:** `feat(999.41): IconLoader prefers compiled-in SVG when BALL_UI_V2 is ON`
