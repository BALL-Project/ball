<objective>
Rebase GLRenderWindow from the removed-in-Qt6 QGLWidget onto QOpenGLWidget: swap the
base class, replace QGLFormat with a QSurfaceFormat compatibility-profile request,
move rendering into initializeGL()/resizeGL()/paintGL(), delete the manual buffer-swap
machinery, reimplement on-screen text as a QPainter overlay, and wire global context
sharing + the default surface format into BALLView's main().

Purpose: this is the core of the phase — the macOS blank-scene blocker is QGLWidget's
inability to be layer-backed. QOpenGLWidget is the supported embedded path. The
compatibility profile keeps glRenderer.C's ~100 fixed-function GL calls working.
Output: glRenderWindow.{h,C} compile clean against QOpenGLWidget; main.C requests the
shared compat context. RenderSetup/scene.C/glRenderer.C still reference the new types —
those files are cleaned in Plans 03 and 04.
</objective>

QSurfaceFormat replacement for the static gl_format_ (RESEARCH.md "Code Examples"):
```cpp
QSurfaceFormat GLRenderWindow::gl_format_ = [] {
    QSurfaceFormat fmt;
    fmt.setProfile(QSurfaceFormat::CompatibilityProfile);
    fmt.setVersion(2, 1);
    fmt.setDepthBufferSize(24);                        // QGL::DepthBuffer
    fmt.setStencilBufferSize(8);                       // QGL::StencilBuffer
    fmt.setSwapBehavior(QSurfaceFormat::DoubleBuffer); // QGL::DoubleBuffer
    fmt.setSamples(4);                                 // QGL::SampleBuffers
#ifndef BALL_OS_DARWIN
#  if !defined(BALL_OS_LINUX) || QT_VERSION < QT_VERSION_CHECK(5,7,0) || QT_VERSION > QT_VERSION_CHECK(5,7,1)
    fmt.setStereo(true);                               // QGL::StereoBuffers (keep existing guards verbatim)
#  endif
#endif
    // QGL::DirectRendering — no QSurfaceFormat equivalent; dropped (it is the default)
    return fmt;
}();
```

Field-by-field QGLFormat -> QSurfaceFormat map (RESEARCH.md §3):
  QGL::DepthBuffer    -> setDepthBufferSize(24)
  QGL::StencilBuffer  -> setStencilBufferSize(8)
  QGL::DoubleBuffer   -> setSwapBehavior(QSurfaceFormat::DoubleBuffer)
  QGL::SampleBuffers  -> setSamples(4)
  QGL::StereoBuffers  -> setStereo(true)  (keep #ifdef BALL_OS_DARWIN / Linux-5.7 guards)
  QGL::DirectRendering-> DROP (no equivalent, default behaviour)
  (implicit 2.1 compat)-> setProfile(CompatibilityProfile) + setVersion(2,1)  [THE KEY ADDITION]
