# Phase 999.61 Plan 01: Qt-lifetime audit + conventions doc Summary

Codified the QObject-lifetime conventions into a canonical 5-rule doc, recorded the six already-fixed UFG sites, and shipped a blocking CI lint that rejects `deleteLater()` inside any destructor — with zero C++ behavior change, because the audit fixes were already in the v1.7.2 base.

## What shipped

1. **`cmake/scripts/check-deletelater-discipline.sh`** — an awk brace-depth scanner over `source/VIEW/**` + `source/APPLICATIONS/BALLVIEW/**` that flags `deleteLater()` inside any `~Class()` body. Ignores non-dtor `deleteLater()`, `= default`/`= delete` dtors, and line-comment mentions. Verified: clean on the real tree (exit 0), catches a synthetic violation (exit 1), passes a good-only tree (exit 0).
2. **`lifetime-discipline` CI job** in `ci.yml` — standalone, blocking, no matrix dependency; runs the script so a lifetime regression fails fast independent of the slow 3-OS build. YAML validated with PyYAML.
3. **`QT-LIFETIME.md` reconciliation** — added the canonical "5 rules" summary, the previously-missing rule 3 / §3a (direct-by-default connections; queued only cross-thread and explicit; the sole cross-thread path in v1.7.4 is `ControllerJob` per 999.59-05, which ARCHITECTURE-CONTRACT.md §4/§6 rely on), a "Case studies" framing of UFG-30/32/18/26, an audit cookbook, and an updated §8 checklist + §9 audit-status (6 sites recorded resolved).
