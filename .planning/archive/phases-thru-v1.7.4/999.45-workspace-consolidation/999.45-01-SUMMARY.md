## Deliverables (8/8 ROADMAP §999.45 sub-items)

1. **ProjectDock** — `include/BALL/VIEW/WIDGETS/projectDock.h` + `.C`. Helper (not a QDockWidget subclass) that calls `QMainWindow::tabifyDockWidget` to group MolecularControl / GeometricControl / DatasetControl into a single left-rail tab group. Canonical objectName `"projectDock"` on the Structures dock.
2. **BottomDrawer** — `include/BALL/VIEW/WIDGETS/bottomDrawer.h` + `.C`. `QDockWidget` with 24px collapsed strip (chevron-up + summary label) and 240px expanded body (QTabBar + QStackedWidget over LogView/FileObserver inner widgets). 200ms OutCubic QPropertyAnimation on maximumHeight.
3. **WorkspaceManager (3 presets)** — `include/BALL/VIEW/KERNEL/workspaceManager.h` + `.C`. Singleton with Preset enum (Default/Classic/Focused/UserDefined), `apply(Preset, QMainWindow*)` walks JSON descriptor and addresses docks by objectName, `save/load(QMainWindow*, name)` for user-defined presets via QSettings INI, `userPresets()` enumeration, `presetChanged` signal.
4. **Shipped .layout files** — `data/BALLView/workspaces/default.layout` + `classic.layout` + `focused.layout`. Portable JSON descriptors (Qt-version-agnostic vs. opaque saveState binary).
5. **First-run migration prompt** — `main.C` post-mainframe-show QMessageBox with two custom buttons ("Try the new workspace" / "Keep my layout (Classic)"). Persisted via QSettings under `[Workspace]/firstRunPromptSeen` + `currentPreset`. Only fires when migration actually performed.
6. **~/.BALLView.pre-v2.bak auto-backup** — `main.C` pre-migration QFile::copy. Never clobbers an existing .bak (multi-upgrade safety).
7. **Status-bar workspace label** — `WorkspaceStatusLabel` (companion class in `workspaceManager.{h,C}`). Clickable QLabel showing current preset name; click opens QMenu with 3 built-in presets + user-defined names + "Save current as…". Wired into Mainframe::show().
8. **configMigration.C** — `include/BALL/VIEW/KERNEL/configMigration.h` + `.C`. `ConfigMigration::run(legacyPath)` migrates `~/.BALLView` → `QStandardPaths::AppConfigLocation/BALLView/BALLView.ini` (Linux: `~/.config/BALLView/`, macOS: `~/Library/Preferences/BALLView/`, Windows: `%APPDATA%/BALLView/`). Idempotent. Appends `[Migration]` provenance marker. Best-effort copies `~/.BALLView_workspaces/` subdir too.

## Decisions Made

- **JSON, not Qt-saveState binary**, for shipped preset descriptors. saveState produces an opaque QByteArray that varies by Qt point release; JSON is portable, greppable, version-explicit, and reconstructed into dock placement programmatically by WorkspaceManager::apply().
- **ProjectDock is a helper, not a QDockWidget subclass**. The 3 controls (MolecularControl / GeometricControl / DatasetControl) all inherit VIEW::DockWidget and BALL's MainControl message bus requires them to stay registered as ModularWidgets. Reparenting them into a plain QStackedWidget would tear bus connections; Qt's `tabifyDockWidget` achieves the visual single-dock-with-tabs effect while keeping each as a first-class registered dock.
- **BottomDrawer extracts QDockWidget::widget() from LogView/FileObserver** to reuse their inner panels (not the outer dock shells). The outer shells are hidden so we don't see two of each; ModularWidget registrations stay intact.
- **WorkspaceManager singleton attached to no parent** (function-local static). It needs to outlive QApplication during shutdown — Qt 6 destroys QApplication children before main() returns, which would crash any late-shutdown callers.
- **Single QStandardPaths::AppConfigLocation for both ConfigMigration target AND WorkspaceManager [Workspace] section** — guarantees one canonical INI file on disk after migration.
- **First-run prompt is a vanilla QMessageBox with two custom buttons**, not a hand-coded SectionHeader dialog. The §5.4 prompt is one line of body + one informative line — QMessageBox is the right tool. Fancy ornamentation deferred to v1.7 RC patch.
