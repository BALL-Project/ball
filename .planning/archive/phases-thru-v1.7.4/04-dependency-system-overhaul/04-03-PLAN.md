<interfaces>
OpenBabel 2.x -> 3.x breaking changes that hit this code (from 04-RESEARCH.md, grep-verified):

  - Bond order:        GetBO()/SetBO()           -> GetBondOrder()/SetBondOrder()
                       (molecularSimilarity.C already uses SetBondOrder/GetBondOrder — likely already 3.x-clean; verify)
  - Valence/degree:    GetValence()/BOSum()/GetHvyValence()
                       -> GetExplicitDegree()/GetExplicitValence()/GetHvyDegree()
  - Element table:     OBElementTable / etab.GetSymbol() / IsCarbon()
                       -> OBElements::GetSymbol() via #include <openbabel/elements.h>
  - Implicit H:        now stored as an atom property; SetImplicitHCount()/GetImplicitHCount();
                       must be managed when adding/removing bonds. createOBMol builds bond-by-bond
                       — this is the subtle one; an obmol->AddHydrogens() call may be needed.
  - Aromaticity:       molecule modification no longer auto-clears aromaticity flags;
                       SetAromaticPerceived(false) forces reperception. molecularSimilarity.C:238
                       calls obmol->SetAromaticPerceived() — verify the polarity for 3.x semantics.
  - BeginModify/EndModify: still exist but perception behaviour changed; createOBMol may need
                       explicit PerceiveBondOrders() or careful flag handling.
  - Header trims:      mol.h no longer pulls in many headers transitively — add explicit
                       #include <openbabel/obiter.h>, <openbabel/elements.h>, <openbabel/bond.h>
                       as the compiler flags them.

Confirmed usage in source/STRUCTURE/molecularSimilarity.C (grep):
  includes: <openbabel/obconversion.h>, <openbabel/parsmart.h>, <openbabel/atom.h>; using namespace OpenBabel;
  types:   OBMol, OBAtom, OBBond, OBConversion, OBSmartsPattern, OBAtomIterator, OBBondIterator
  methods: NewAtom, NewBond, SetBondOrder, GetBondOrder, SetAromaticPerceived,
           BeginAtoms/EndAtoms, BeginBonds/EndBonds, GetBeginAtom/GetEndAtom
  NOTE: createOBMol() builds molecules atom+bond-by-bond, then calls obmol->SetAromaticPerceived()
        at the end (line ~238). This is the highest-risk spot for the implicit-H + aromaticity changes.

sources.cmake guards (confirmed present, leave intact):

  source/APPLICATIONS/TOOLS/sources.cmake:68  IF(BALL_HAS_OPENBABEL)
