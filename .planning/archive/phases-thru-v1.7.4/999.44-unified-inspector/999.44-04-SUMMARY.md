# Phase 999.44 Plan 04: Representation tab Summary

**Largest single deliverable of the 999.44 continuation.** Sub-PRs 4.3 + 4.4. Read-only mirror Controllers for all 5 Representation-relevant dialog domains + 4 Inspector sections (RepHeader / Model / Coloring / Material).

## Scope decision (operating-contract scope-trim)

Ship Controllers for all 5 domains (Model / Coloring / Material / Label / Clipping) so the cut-over is mechanical, but **sections only for Model / Coloring / Material** in this plan. Label + Clipping sections deferred to a follow-up 999.44-04b RC patch — Controllers are landed and ready.

Rationale: 5 sections × ~250 LOC each = 1250 LOC of section UI alone; 3 sections + 5 Controllers is the load-bearing minimum to demonstrate the pattern across multiple Controllers + show real user-visible Inspector content.

## What landed

**Controllers (read-only mirror, ~80 LOC each):**
- ModelController       — modelType / drawingMode / drawingPrecision / transparency
- ColoringController    — coloringMethod enum
- MaterialController    — ambient / diffuse / specular / shininess
- LabelController       — labelText / labelType / fontSize (no section yet)
- ClippingController    — enabled / offset / capped (no section yet)

**Sections:**
- RepHeaderSection      — current-representation picker + summary
- ModelSection          — 3 QComboBoxes + transparency slider, 100ms debounced commit
- ColoringSection       — coloring-method QComboBox
- MaterialSection       — 4 sliders (ambient/diffuse/specular/shininess)

**Bus adapter:**
- RepresentationInspectorAdapter — `ConnectionObject` listening for `RepresentationMessage`.

**InspectorView API surface:** `attachRepresentationTab()`, `setRepresentations(reps, active)`, `setActiveRepresentation(rep)`.
