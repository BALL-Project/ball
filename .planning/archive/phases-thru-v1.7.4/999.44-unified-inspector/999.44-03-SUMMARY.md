# Phase 999.44 Plan 03: Selection tab Summary

**Selection-tab live wiring via existing MainControl message bus** — sub-PR 4.2.

## What landed

3 sections + ConnectionObject-based selection-bus adapter:
- `SelectionSummarySection` — atom/residue/chain/molecule counts.
- `PropertiesSection` — per-atom element/position/charge/radius when single Atom selected.
- `QuickActionsSection` — Clear / Invert buttons wired to MainControl slots.
- `SelectionInspectorAdapter` — listens to `ControlSelectionMessage` and `NewSelectionMessage`.

`InspectorView` new API: `attachSelectionTab(MainControl*)` + `setSelection(std::list<Composite*>)`. Mainframe constructs the adapter post-InspectorDock.
