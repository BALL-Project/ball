## Decisions Made
- **Working backend, not the dead field:** route through `Representation::setTransparency()` (0-255 per-vertex alpha) which GLRenderer's transparent pass keys off via `rep.getTransparency()`, NOT `Stage::Material.transparency` (POVRay/RTfact-only; RTfact disabled). This is the corrected backend the plan was revised to require, and avoids reproducing #527.
- **Shared state with the Model section** rather than a divergent duplicate: both sections read/write the same Representation transparency, so changing one reflects in the other.
- **`rep_->update(false)`** (cheap, no composite re-walk) for the transparency-only refresh, mirroring ModelController's transparency path.
