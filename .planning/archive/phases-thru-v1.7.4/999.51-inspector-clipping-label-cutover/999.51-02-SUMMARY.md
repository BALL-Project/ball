## Decisions Made

- **Mode mapping:** the LabelSection combobox is ordered to match the `LabelModel::Mode` enum so the
  controller's int `labelType` maps 1:1 (0=ALL_ITEMS, 1=ALL_ATOMS, 2=ALL_RESIDUES, 3=ONE_LABEL); a
  `switch` in `apply()` converts the int to the enum (defaulting to ALL_ITEMS).
- **Selection-targeted apply:** unlike the per-Representation Material section, `LabelController::apply()`
  builds a label against the current molecular selection (`getMolecularControlSelection()`), exactly as
  `LabelDialog::accept()` does. With no selection it logs and returns gracefully. `setRepresentation`
  is still wired as the binding/revert hook for parity with the other sections.
- **Color/font:** the controller's Q_PROPERTY surface (text/type/fontSize) was left unchanged per the
  plan — color uses the `LabelModel` default; the font is built as `QFont("Helvetica", font_size_)`,
  mirroring the legacy dialog's Helvetica 12 default.
- **Guards:** the `MainControl::isBusy()` busy-guard is retained (mirroring Model/Clipping); no
  `ControllerApplyGuard` (the label-insert path emits no synchronous `*Changed` re-entry).
