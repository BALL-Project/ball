# Phase 02.2 Plan 02: GitHub Actions CI Matrix Summary

**A 3-OS GitHub Actions build matrix with a headless render smoke check and a
legacy-GL lint gate — the early regression net Phases 3-9 land against. CI is
fully green on run 25859952862 (`1959d9b`), all four jobs passing.**

## What shipped

`.github/workflows/ci.yml` — triggers on push + PR to `master` / `v1.6-modernization`:
- **build matrix** (`strategy.matrix.include`, axis-extensible): macOS-arm64 + Linux blocking, Windows `continue-on-error` (non-blocking until Phase 4's vcpkg manifest). Native package managers (Homebrew / apt) mirroring `BUILD-macos.md`; Homebrew + apt + ccache caching.
- **render smoke check** wired into the macOS (native) and Linux (`xvfb-run` + `LIBGL_ALWAYS_SOFTWARE=1`) build jobs — runs `render-smoke-check.sh` (Plan 01), asserts a non-blank PNG, cross-checks the `BALLVIEW_GL_DIAG` line.
- **lint job** — runs the `check-no-legacy-gl-symbols.sh` grep gate.
- failure-artifact upload (blank PNG + log) on smoke-check failure.

## CI bring-up — 2 iterations to green (every platform exposed its own first-clean-build quirk)

| Iteration | Failure | Root cause | Fix |
|-----------|---------|-----------|-----|
| Run 1 | **macOS build** red | C++ standard applied as a raw `-std=c++14` flag appended to `CMAKE_CXX_FLAGS` *after* `BALLConfiguration`'s feature-detection ran. CI's **AppleClang 15** (older default standard than local AppleClang 21) → `BALL_HAS_NOEXCEPT`/`BALL_HAS_THREAD_LOCAL` mis-detected, Eigen TUs compiled sub-C++14 → `#error Eigen requires at least c++14`. | `3ac3f24` — `CMAKE_CXX_STANDARD 14` set immediately after `PROJECT()`, before feature detection. Deterministic on every compiler. |
| Run 1 | **Linux link** red | Ubuntu's `liblpsolve55.a` is built **without `-fPIC`** — a non-PIC static archive can't link into shared `libBALL` (`ld: relocation R_X86_64_PC32 ... can not be used when making a shared object`). | `1959d9b` — drop `liblpsolve55-dev` from Linux apt deps + `-DUSE_LPSOLVE=OFF` on Linux. lp_solve is optional; macOS keeps it. |
| (pre-emptive) | lint would be red | `glDisplayList.h` still `#include`d `QtOpenGL/qgl.h`; grep gate matched historical comments. | `da043c1` (port `glDisplayList.h` → `QtGui/qopengl.h`) + `4c91600` (gate skips comment-only lines). |
