<interfaces>
**Ninja's .ninja_log format:** tab-separated `start_ms end_ms mtime command-hash output-file`. The (end_ms - start_ms) field gives per-TU compile time. File lives at `build/ci-{platform}/.ninja_log` after a build.

**Existing ccache instrumentation (commit bbac526, lines ~125-145 of ci.yml):** wraps Build step with `ccache --zero-stats` before and `ccache --show-stats` after. Same shape works for the ninja-log capture — wrap as a post-Build step.

**Top-20 parse (one-liner, runs in CI shell):**
```bash
awk -F'\t' 'NF>=5 {printf "%8d ms  %s\n", $2-$1, $5}' build/ci-{platform}/.ninja_log | sort -rn | head -20
```

**Artifact upload:** `actions/upload-artifact@v4` (current pin; will bump to v6 in Phase 999.20 — coordinate).

**Why each platform separately:** TU timing varies dramatically by toolchain (MSVC vs clang vs gcc), so per-platform artifact + per-platform top-20 is the useful unit. Single artifact per matrix entry, named `ninja-log-{platform}-{sha}` for discoverability.
</interfaces>
</context>

    Step shape (use platform-matching shell — bash for macOS+Linux, pwsh for Windows):

    For macOS + Linux:
    ```yaml
          - name: Top-20 slowest TUs (${{ matrix.os }})
            if: (success() || failure()) && (matrix.os == 'macos-arm64' || matrix.os == 'linux-x64')
            shell: bash
            run: |
              if [ -f build/ci-${{ matrix.os }}/.ninja_log ]; then
                echo "=== Top-20 slowest TUs (${{ matrix.os }}) ==="
                awk -F'\t' 'NF>=5 {printf "%8d ms  %s\n", $2-$1, $5}' build/ci-${{ matrix.os }}/.ninja_log \
                  | sort -rn | head -20
              else
                echo "WARN: .ninja_log not found at build/ci-${{ matrix.os }}/.ninja_log"
              fi

          - name: Upload .ninja_log artifact (${{ matrix.os }})
            if: (success() || failure()) && (matrix.os == 'macos-arm64' || matrix.os == 'linux-x64')
            uses: actions/upload-artifact@v4
            with:
              name: ninja-log-${{ matrix.os }}-${{ github.sha }}
              path: build/ci-${{ matrix.os }}/.ninja_log
              retention-days: 90
    ```

    For Windows (pwsh shell):
    ```yaml
          - name: Top-20 slowest TUs (windows-x64)
            if: (success() || failure()) && matrix.os == 'windows-x64'
            shell: pwsh
            run: |
              $logPath = "build\ci-windows\.ninja_log"
              if (Test-Path $logPath) {
                Write-Host "=== Top-20 slowest TUs (windows-x64) ==="
                Get-Content $logPath | ForEach-Object {
                  $f = $_ -split "`t"
                  if ($f.Length -ge 5) {
                    [PSCustomObject]@{ ms = [int]$f[1] - [int]$f[0]; tu = $f[4] }
                  }
                } | Sort-Object -Property ms -Descending | Select-Object -First 20 | Format-Table -AutoSize
              } else {
                Write-Host "WARN: .ninja_log not found at $logPath"
              }

          - name: Upload .ninja_log artifact (windows-x64)
            if: (success() || failure()) && matrix.os == 'windows-x64'
            uses: actions/upload-artifact@v4
            with:
              name: ninja-log-windows-x64-${{ github.sha }}
              path: build\ci-windows\.ninja_log
              retention-days: 90
    ```

    The `if: success() || failure()` guard ensures the step runs even if the Build step failed — `cancelled()` would also be present in production-grade workflows but skip on cancel is the standard tradeoff.

    Use `actions/upload-artifact@v4` (current pin); Phase 999.20 will bump to v6 separately.

    Use the existing matrix variable for path discovery (`ci-${{ matrix.os }}` for macOS/Linux which map to `ci-macos`/`ci-linux` per CMakePresets — confirm against the presets file).
