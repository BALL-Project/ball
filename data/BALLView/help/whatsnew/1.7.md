# What's new in BALLView 1.7

The BALLView Refresh wave (Phases 999.40 – 999.49) is the largest
user-facing overhaul since the v1.0 release. Highlights:

## A consolidated workspace

- **Project dock** — Structures, Representations, and Datasets now
  live as tabs in a single left rail (collapsible).
- **Bottom drawer** — Logs and File observer share a 24 px → 240 px
  animated bottom strip.
- **Unified Inspector** — Display / Model / Material / Coloring /
  Stage / Lights / Stereo / Background / Camera are all reachable
  from the right rail without juggling dialogs.

## Faster to first molecule

- New **Welcome screen** with one-click sample structures, a recent
  files list, and the PubChem fetcher right where you start.
- **Command palette** (Cmd/Ctrl + K) — search every menu action by
  name. Type `?` for help, `>` to filter by File menu, `:` for
  quick-actions.

## Look & feel

- HiDPI-correct toolbar icons + a single neutral theme palette.
- Markdown-rendered help and tutorial files; the old QtWebEngine
  dependency is gone for the built-in help system.

## What's coming in 1.8

- Per-user font scaling (Normal / Large / Extra Large) and a
  keyboard-only walkthrough.
- Full removal of the legacy "Classic" 5-dock workspace.
- Per-model Inspector controls (Ball & Stick radii, Cartoon ribbon
  shape, Surface probe radius) and richer per-method colouring options.
